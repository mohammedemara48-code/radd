# ردّ

استرجاع صور من تخزين أندرويد، أوفلاين، من غير رفع الملفات لأي موقع.

التطبيق مش بيقرأ قطاعات الفلاش اللي اتمسحت خالص. بيلاقي اللي لسه له أثر: سلة الحذف، `LOST.DIR`، الملفات المخفية، والصور المدفونة في الكاش.

## تثبيت الموبايل

1. حمّل [public/radd.apk](public/radd.apk).
2. اسمح بالتثبيت من المصدر ده.
3. افتح **ردّ** واضغط **السماح بقراءة الذاكرة**، وبعدين فعّل إدارة كل الملفات.
4. ارجع واضغط **فحص الذاكرة** وسيب التطبيق مفتوح.
5. **حفظ المسترجع** بينسخ اللقطات في مجلد `RaddRecovered`.

مفيش صلاحية إنترنت في التطبيق.

## الموقع

المعاينة والمعمل على الويب. الفحص الحقيقي على الموبايل من ملف الـ APK.

```bash
npm install
npm run dev
```
