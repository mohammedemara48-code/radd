# ردّ

تطبيق أندرويد أوفلاين لاسترجاع الصور من تخزين الموبايل. مفيش رفع ولا سيرفر ولا صلاحية إنترنت.

## بيعمل إيه

التطبيق مش بيقرأ قطاعات الفلاش اللي اتمسحت (ده محتاج روت). بيلاقي اللي لسه له أثر على التخزين، من سبع مصادر:

1. سلة المحذوفات (Trash) وملفات `.trashed-*`.
2. `LOST.DIR`.
3. الصور المصغّرة (`.thumbnails`).
4. واتساب.
5. تيليجرام.
6. الملفات والمجلدات المخفية (فيها `.nomedia`).
7. صور مدفونة جوه ملفات الكاش، بنحتها من JPEG/PNG/WebP/HEIC/AVIF.

كل صورة بتتعلّم "سليمة" أو "ناقصة" (الهيدر سليم والداتا ناقصة). المكرر بيتشال بالـ SHA-256، والصور اللي لسه ظاهرة في المعرض بتتستبعد.

من غير حد أقصى لعدد الملفات أو حجم التخزين. الفحص بيشتغل كخدمة أمامية بإشعار وزر إيقاف، والنتايج بتتحفظ في Room فمتضيعش لو التطبيق اتقفل.

الاسترجاع بينسخ لمجلد `RaddRecovered` من غير ما يكتب فوق أي ملف، بيتأكد من الحجم والـ SHA-256، بيحافظ على تاريخ الملف الأصلي، وبيبلّغ المعرض.

## التثبيت

1. من [Releases](https://github.com/mohammedemara48-code/radd/releases/latest) نزّل ملف `.apk`.
2. اسمح بالتثبيت من المصدر ده.
3. افتح **ردّ**، اسمح بالإشعارات، وفعّل **إدارة كل الملفات** (أندرويد 11+).
4. اضغط **فحص الذاكرة**. التطبيق يكمّل لو شاشتك قفلت.

أندرويد 8.0 (API 26) فما فوق. التطبيق مش على Google Play لأن صلاحية `MANAGE_EXTERNAL_STORAGE` مقيّدة هناك.

بصمة شهادة التوقيع (SHA-256): `2E:C9:80:1C:86:71:81:B8:A7:32:13:84:7E:A2:FA:7B:59:A2:A3:F7:80:A4:0F:95:34:62:F0:42:C4:C8:E8:B2`

## حدود صريحة

- بعد "Android 13" التطبيقات مش بتقدر تقرأ `Android/data` لتطبيقات تانية. `Android/media` بتتقرا.
- لو الملف اتكتب فوقه فعلًا، مفيش طريقة ترجّعه بدون روت.
- الاسترجاع على الجهاز الحقيقي لسه محتاج تجربة على أجهزة وروم مختلفة. ده v1.0.0.

## بناء من المصدر

الكود في `android-app/`. محتاج JDK 17 وAndroid SDK 35.

```bash
cd android-app
gradle :app:testDebugUnitTest                 # الاختبارات (Robolectric + محرك على شجرة تخزين صناعية)
gradle -Ppreviews=true :app:testDebugUnitTest # بيعيد رسم صور المعاينة في previews/
gradle :app:assembleRelease                   # محتاج ~/keys/radd-release.properties
```

ملف التوقيع بيتقرا من `~/keys/radd-release.properties` (المفاتيح: `storeFile`, `storePassword`, `keyAlias`, `keyPassword`) أو من `-PkeystoreProps=<path>`. المفتاح نفسه مش في المستودع، وضياعه معناه إن التحديثات مش هتتثبت فوق النسخة الموجودة.

التصميم والتدقيق في `docs/`. المعاينات في `previews/`.

## الموقع

نسخة ويب للمعاينة والتجربة فقط، الفحص الحقيقي من التطبيق.

```bash
npm install
npm run dev
```
